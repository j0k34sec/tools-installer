# J0K34SEC Security Tools Installer - Project Context

## 🎯 Project Overview
**Name**: J0K34SEC Security Tools Installer  
**Version**: 1.0.0  
**Type**: Bash-based multi-platform security tools installer  
**Repository**: https://github.com/j0k34sec/tools-installer  
**Purpose**: Automated installation and management of security/bug hunting tools for penetration testers and security researchers

## 📁 Project Structure
```
tools-installer/
├── main.sh                     # Main orchestrator script
├── manage_tools.sh             # Tool management utility
├── README.md                   # User documentation
├── logo.png                    # Project branding
├── config/
│   └── gau.toml               # GAU tool configuration
└── installers/
    ├── arch_installer         # Arch Linux installer
    ├── debian_tools_installer # Debian/Ubuntu installer
    ├── kali_installer         # Kali Linux installer
    └── go_tool_installer.sh   # Go-based tools installer
```

## 🚀 Quick Start Commands
```bash
# Initial installation
bash main.sh

# List installed tools
bash manage_tools.sh list

# Uninstall all tools
bash manage_tools.sh uninstall

# One-liner installation from GitHub
git clone https://github.com/j0k34sec/tools-installer.git && cd tools-installer && bash main.sh
```

## 🔧 Technical Details

### Supported Operating Systems
- ✅ Kali Linux
- ✅ Ubuntu/Debian
- ✅ Arch Linux (including Manjaro, EndeavourOS)
- ✅ Other Debian-based distributions

### Dependencies
- **Required**: Go (latest), Git, Python 3.6+
- **Build Tools**: base-devel (Arch) or build-essential (Debian/Ubuntu)
- **Libraries**: libcap (for network tools)

### Installation Directories
- **Tools Location**: `~/Tools/`
- **Symlinks**: `/usr/local/bin/`
- **Logs**: `~/Tools/install_errors.log`
- **Config**: `~/.config/` (for individual tools)

## 🏗️ Architecture

### Installation Flow
1. **OS Detection** → Identifies distribution via `/etc/os-release`
2. **Dependency Check** → Verifies/installs Go, Git, Python
3. **Directory Setup** → Creates `~/Tools` directory structure
4. **Tool Installation** → Runs OS-specific installer script
5. **Configuration** → Sets up PATH, creates symlinks
6. **Verification** → Confirms successful installation

### Installation Methods
- **System Packages**: Via `apt` or `pacman`
- **Go Tools**: Using `go install`
- **Git Repositories**: Cloning and building from source
- **Python Tools**: Virtual environments with pip
- **Binary Downloads**: Direct downloads for pre-built tools

## 🐛 Common Issues & Solutions

### Installation Issues
```bash
# Go not found
sudo apt install golang-go  # Debian/Ubuntu
sudo pacman -S go           # Arch

# Permission denied
sudo chmod +x main.sh
sudo chmod +x manage_tools.sh

# Tools not in PATH after installation
source ~/.bashrc  # or ~/.zshrc
```

### Tool-specific Issues
```bash
# Python tool not working
cd ~/Tools/<tool-name>
source venv/bin/activate
pip install -r requirements.txt

# Go tool not found
export PATH=$PATH:$HOME/go/bin
```
